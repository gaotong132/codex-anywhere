# 复合控件回归

点击下拉框或卡片时，不能触发其中独立的删除按钮。页面脚本在有限个可见位置进行检查，避开独立子操作，保留普通按钮内部图标的点击。父控件完全被其他操作覆盖时仍返回不可点击，调用方可使用目标子控件自己的快照引用。

行内包裹元素的 overflow，以及不属于定位元素包含块的祖先，可能导致矩形裁剪与浏览器实际渲染不一致。有限次浏览器命中检查可以恢复真正可见的片段；隐藏与私有分支仍然排除，覆盖层仍阻止点击。

`test/composite-controls.test.ts` 覆盖内嵌操作、自定义无文字删除图标、普通装饰、裁剪内容和隐藏／私有分支。`test/fixtures/composite-controls.html` 用真实浏览器验证下拉框，以及位于裁剪祖先内的固定定位规格按钮和底部按钮。模拟页面通过不代表真实控制台已验收。

模拟下拉框会在窗口尺寸变化时关闭。成功的原生点击和截图现在复用同一已授权文档的调试连接，空闲60秒，或导航、撤销、断线、操作失败时释放。测试同时覆盖迟到的连接建立、用户取消，以及新文档的连接归属。这避免调试提示条改变窗口尺寸后立刻收起刚打开的菜单。[TinyNG下拉框源码](https://github.com/opentiny/tiny-ng/blob/main/src/drop/lib/src/TiDropComponent.ts)是位置变化时收起菜单的实际组件示例。
