# Browser extension review and refactor (2026-09-09)

English | [简体中文](refactor-2026-09-09.zh-CN.md)

The review starts from `de92753` and covers side-panel selection and single pairing, reconnection, document consent,
managed children, DOM reads, native clicks, screenshots, zoom and Connector/MCP routing. The extension remains experimental.

## Changes

| Finding | Resolution |
| --- | --- |
| Consent orchestration also contains drivers and tab cleanup | Extract `page-runtime.ts` and `managed-tab-lifecycle.ts`; the worker retains consent, revocation and result ownership |
| Native click waits are inconsistently bounded | Share `deadline.ts` with screenshots and zoom; bound preparation, permission, attachment, input and cleanup; late attachments are disposed without input |
| Target matching depends on JSON field order | Strictly parse, then compare device, tab, document and origin; extra fields and changed identities still fail |
| Snapshot repeatedly reads shared ancestor layout | Reuse style/rectangle reads only within one synchronous snapshot; later snapshots and action phases read live DOM |
| Child reuse reads can outlive the source request | Bound reads and stop on expiry without late activation or fallback tab creation |
| Debugger documentation contradicts current behavior | Document same-document reuse until 60 seconds idle, with earlier release on navigation, revocation, disconnection or failure |

A Binding's object identity still represents its lifetime. Asynchronous work retains generation, identity, document,
sequence and busy checks. Injected scripts remain self-contained. Tool schemas, protocol and saved pairing formats are unchanged.

On a fixture with 80 nested buttons, all 80 controls remain available. Style reads drop from 2024 to 165 and rectangle
reads from 1126 to 163. These are fixture API counts, not a claim about total latency on arbitrary sites.

## Validation

- `npm run check`: type checks and all 361 main tests passed.
- `npm run test:extension`: all 100 extension tests passed, including late attachments, stalled input, stale refs and activity/consent changes during cleanup.
- `npm run build`: Web and Node builds passed.
- Isolated real Chrome: one pairing, side-panel reopening, MCP/encrypted Relay zoom/click/screenshot routing, mask alignment, background-tab isolation and consent rotation after reload passed.
- Isolated real Chrome: repeated-link reuse, eight chained child openings retaining five ordinary children, preservation of root/manual/pinned/edited tabs, and cross-origin consent handoff passed.

Reload the extension at its existing path; no new pairing, permissions or tools are required. A timed-out Chrome call
may still have acted: inspect the page before deciding how to proceed, never replay uncertain writes automatically.
Synthetic Chrome checks do not cover every cloud console widget, daily Edge profile, or long sleep/wake cycle.
