本轮以 `de92753` 为基线，审视侧栏选择/一次配对、连接与重连、授权文档生命周期、受控子页、

## 已处理的问题

| 发现 | 处理与验证 |
| --- | --- |
| 后台授权代码同时包含页面驱动和子页清理 | 提取 `page-runtime.ts` 与 `managed-tab-lifecycle.ts`；授权、撤销和结果回传继续由后台统一负责 |
| 点击中的 Chrome 调用没有一致的等待上限 | 点击、截图、缩放共用 `deadline.ts`；补齐点击准备、权限、连接、事件与清理的超时，迟到连接只释放、不发送输入 |
| 文档目标依赖 JSON 属性排列顺序 | 先严格解析，再逐字段比较设备、页签、文档和 Origin；仍拒绝额外字段或更换身份 |
| 同一快照反复读取共同祖先的样式与位置 | 只在同步快照调用内复用布局读数；后续快照、点击阶段和其他操作重新读取 |
| 子页复用的读取可能超过源操作截止时间 | 复用检查采用有界等待，超时不继续激活或回退为重复开页 |
| 文档同时描述“立即断开”与“空闲释放” | 统一为同一已授权文档成功操作复用、空闲 60 秒释放；导航、撤销、断线或失败时提前释放 |

授权 Binding 的对象身份仍表示其生命周期。异步操作继续检查连接代次、对象身份、文档、序号与忙碌状态。
页面脚本保持可序列化的自包含函数，未拆成注入后不可访问的模块依赖。工具参数、协议和保存的配对格式不变。

80 个嵌套按钮的固定测试页保留全部 80 个控件，样式读取从 2024 次降到 165 次，位置读取从 1126 次降到 163 次。
这是该样例的 API 调用次数对比，不代表所有网页的耗时或模型调用速度提升。

## 验证结果

- `npm run check`：全部类型检查与 361 项主项目测试通过。
- `npm run test:extension`：100 项扩展测试通过，包括迟到连接、无响应鼠标事件、过期引用、清理期间活动与授权变化。
- `npm run build`：Web 和 Node 构建通过。
- 独立真实 Chrome 配置：一次配对与重开侧栏、MCP→加密 Relay→插件的缩放/点击/截图、遮挡位置、背景页隔离、刷新后的授权轮换通过。
- 独立真实 Chrome 配置：重复链接复用、连续打开 8 个子页后保留最近 5 个普通子页、保护根页/手动页/固定页/未保存输入，以及跨源等待授权通过。

更新后重载原路径的插件即可，无需重新配对。此次没有新增权限或工具。
浏览器调用超时不能证明浏览器取消了动作；不确定写操作仍须先读页面确认，禁止自动重放。
真实 Chrome 验收使用合成页面，不等于覆盖所有云控制台组件、用户日常 Edge 配置或长时间休眠恢复。
