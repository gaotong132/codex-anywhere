# Contributing

Thanks for helping improve Codex Anywhere.

Before opening a pull request:

1. Keep the project single-user and self-hosted by default.
2. Do not add telemetry, cloud conversation storage, or secrets to logs.
3. Preserve manual approval for privileged Codex actions.
4. Add or update tests for protocol and security-sensitive behavior.
5. Run `npm run check` and `npm run build`.

Use GitHub private vulnerability reporting for security issues. Public issues and fixtures must not
contain credentials, private hosts, IP addresses, conversation content, or local filesystem paths.
