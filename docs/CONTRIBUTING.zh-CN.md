# 参与贡献

[English](CONTRIBUTING.md) | 简体中文

感谢你帮助改进 Codex Anywhere。

提交 Pull Request 前请确认：

1. 项目默认定位仍是单用户、自托管。
2. 不要加入遥测、云端会话存储，也不要把密钥写入日志。
3. 涉及高权限的 Codex 操作必须保留人工批准。
4. 协议或安全敏感行为发生变化时，应新增或更新测试。
5. 运行 `npm run check` 和 `npm run build`。

安全问题请使用 GitHub 私密漏洞报告。公开 Issue 和测试数据不得包含凭据、私有主机名、IP 地址、
会话内容或本地文件系统路径。
