# v0.4.5 — 2026-10-22

[English](release-0.4.5.md) | 简体中文

本版本汇总 v0.4.4 之后的改动。保留协议版本 4 和已有配对身份；Browser Agent 仍是**可选的实验性附加特性**。

## 功能与改进

- Web 消息通过桌面原生用户输入入口发送，保留普通用户消息和运行中补充指令的语义；执行端确认接收后才显示送达提示。
- 读取模型、思考强度和权限时不切换电脑页面；限制昂贵状态读取，复用状态推送，保持紧凑的加载动效。
- Web 可修改权限，包括新建会话和桌面尚未接管的空闲会话；仍遵循 Connector 能力和必要的明确确认。
- 多设备使用持久唯一 ID，拒绝冲突注册，支持跨浏览器同步自定义名称。
- ECS 会话可并发运行，输出、审批和停止按会话隔离；确认后可删除空闲的无桌面会话，不删除项目文件。
- 修改已发送消息并重发：替换原消息，撤回后续对话记录，保留原附件。不撤销已执行的文件修改或外部操作；阻止忙碌会话、过期确认和结果不明时的危险重试。
- 优化 Markdown 表格、中文加粗、处理过程和历史分页；支持按需预览本地及生成的栅格图片、下载原图。
- 将线上功能改动纳入仓库，仅部署已提交源码；私有配置与回退备份保留在仓库之外。

## 升级

1. 检查各节点的本地改动和活动任务，保存当前提交、镜像 ID/标签、私有配置、设备注册表和 Connector 身份。保留业务会话与工作区，等待 Connector 持有的任务结束后再重启。
2. 在各节点的干净工作区选择发布版本。Windows 更新依赖前，按部署指南停止本安装的空闲 Connector 与守护器，释放已加载的原生模块：

   ```sh
   git fetch origin --tags
   git checkout --detach v0.4.5
   npm ci
   npm run build
   ```

   仅运行 Relay 的主机在 Docker 内构建，不需要宿主机 Node/npm。Connector 主机需要 Node.js 22+，依赖须与实际服务账号、运行时匹配。保留无关本地改动，不要直接 reset 覆盖。
3. Relay 执行 `docker compose build bridge`、`docker compose up -d --no-build bridge`；同机 Connector 空闲后构建 Node 产物并重启 `codex-anywhere-connector.service`。验证容器健康、公网 HTTPS、认证后的 WSS 和两个执行节点。`relay.sh update` 跟随 main，不固定 tag、不负责备份，也不等待任务空闲。
4. Windows 构建后，通过既有启动器/守护器实际重启 Connector。只重跑安装器不一定替换正在运行的进程，参见[实际重启步骤](deployment.zh-CN.md#windows-连接器实际重启)。保留 DPAPI 配置和身份，不停止 Codex Desktop。
5. 完整刷新 Web，侧栏可使用“重新加载聊天”。检查原有历史、图片、文本/HTML 预览和确认后的文件下载。不需要数据库迁移或重新配对，源文件仍须存在。
6. 使用插件时运行 `npm run build:extension`，将整个 `extension/dist` 保留在原安装路径并重新加载。该目录是生成产物，不提交 Git。本版没有新增浏览器权限，`dev (build …)` 仍表示解压加载的实验构建。
7. 验收后记录当前与上一版镜像 ID。核对全部容器（含停止容器）及并行构建，仅逐项删除明确的旧项目镜像引用。保留最近两次部署及基础/容器依赖镜像；不清理共享缓存、数据卷或其他任务容器。验收失败时恢复匹配镜像/代码，保留升级后合法的设备注册变化。

## 验证与限制

Windows 本地发布验证通过四项 TypeScript 检查、631 项主测试、100 项扩展测试、Web/Node 生产构建，以及 45 份 Markdown 文档与版本元数据校验。功能实现阶段已用 PC、ECS 临时真实会话验证；PC 的编辑重发验证覆盖未接管会话的临时运行时路径。桌面已接管会话的原生编辑有回归测试，但该次未独立完成端到端验证。

请同时升级 Relay 和 Connector；协议编号兼容不意味着旧 Connector 支持新增动作。等待空闲后重启 Connector，再刷新 Web。无需重新配对或迁移数据库，已有设备 ID 和名称保留。带日期的旧审查报告只代表对应版本的证据。

发布附件中的扩展 ZIP 是解压加载版本：解压至固定目录，再在 Chrome/Edge 开发者模式加载。覆盖已安装目录并重新加载可保留配对；另一台电脑需要独立授权。发布附件同时提供校验和。
