## 覆盖范围与判断

复查请求重放与加密通道生命周期、Web 历史合并与下载恢复、审批轮询、上传/下载/预览边界、HTTP 边界和浏览器授权。已有回归覆盖鉴权、执行环境隔离、重连、渲染及浏览器操作。这是按风险开展的审查，不代表每一行代码或每种部署都没有缺陷。

Relay、Connector、共享协议和 Web 的现有职责划分仍然合理，不为减少行数而重写大型 UI 或 Codex 适配器。本轮抽取附件清理模块有具体收益：普通上传无需引入图片预览依赖链，也不再重复处理清理异常。

## 已复现问题

| 问题 | 证据 | 修复 |
| --- | --- | --- |
| 并发删除过期文件导致上传失败 | 对 30 个过期文件同时执行四次清理，在 Windows 复现三次拒绝，包括 EPERM。图片上传会传播异常；普通文件上传的旧容错会提前结束剩余扫描。 | 按规范化目录串行扫描，逐条跳过已消失文件，成功或失败后释放队列；真实权限和 I/O 错误仍然上报。 |
| 等长修改临时文件导致校验值不符 | 两字节上传临时文件被改写为另两字节后，旧代码仍接受。 | 复用公共文件快照比较，在打开/追加和完成前验证；核对已打开句柄，并在写入成功后记录新元数据。 |

两个回归用例均先在旧实现失败，再在修复后通过。另一个用例验证清理失败后仍能再次扫描。现有传输测试覆盖字节不变、边界、所有权、取消和过期。

## 依赖与验证

- 升级 file-type 22.1.1、Zod 4.6.7、Vite 8.3.4、Sass 1.105.1，直接依赖保持精确版本并同步锁文件。
- 四组 TypeScript 检查和 471 个主测试通过；打 tag 前检查 Web/Node 生产构建、编译后插件测试；文档检查覆盖双语链接、锚点和版本元数据。
- 官方 npm 源审计保留 KaTeX/Mermaid 链上的两项低风险条目，没有中、高或严重项。Mermaid 12 改变浏览器要求和渲染默认值，暂缓，需另行验证目标手机。
- 部署须保留服务器私有改动、注册表和配对身份，备份旧运行版本，等待 Connector 所有任务空闲，检查公网 HTTPS 与两条路由的已鉴权 WSS。部署证据保存在运维本地，tag 本身不代表已部署。

## 保留边界

元数据检查识别普通外部修改，不是原子文件系统快照，也不能防御控制 Connector 宿主系统的攻击者。清理串行化仅在本进程内有效。上传文件仍为临时文件，下载仍在浏览器组装 Blob；重放保护仍有进程和容量边界。浏览器自动化不代表手机真机体验已验收。公开版本不纳入 ECS 私有并发/删除修改。

本版本也包含此前已经验证的电脑端审批恢复修复，操作见[部署指南](deployment.zh-CN.md#电脑端审批等待的恢复v043)。原 [v0.4.2 审查](code-review-2026-10-17.zh-CN.md)保留为历史记录。
