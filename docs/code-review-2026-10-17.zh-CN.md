本轮复查 Web 会话配置、列表与请求重放，Connector 文件上传、下载与预览生命周期，浏览器会话授权，以及已有重连、身份隔离和加密通道回归。范围覆盖关键路径，不等于每一行代码或每一种部署环境均已证明无缺陷。此前的有界文件读取、请求缓存重构见[上一轮报告](code-review-2026-10-16.zh-CN.md)。

## 发现与调整

| 项目 | 证据与处理 |
| --- | --- |
| 重放请求引用可变草稿 | 调用后修改嵌套输入及 threadId，再重放同一请求；旧实现回归失败。发送前 structuredClone，保留原始数据。 |
| 权限图标累积 | 相邻 React 控件 key 相同；已加入独立前缀。此前公网桌面/窄屏连续切换 20 次均保持一个权限控件。 |
| 文件改写测试偶发失败 | 等长快速改写未必改变文件系统时间戳。测试明确更新时间，仍不把元数据检查当作原子快照。 |
| PC 会话整理 | 用户选择可恢复归档；使用原生 set_thread_archived，不引入永久删除。检查状态、原会话身份、明确确认、响应身份；归档撤销该会话浏览器授权并丢弃归档前的列表请求。 |

## 重构取舍

归档确认界面独立为组件，复用既有原生客户端、请求分派、重放缓存与样式。未改写大体积 App/历史投影模块：这次没有足够证据证明整体重写的收益大于回归风险。未新增生产依赖或改变线协议；ECS 工作区的私有并发与删除功能单独保留，不并入本次公共发布。

## 验证与边界

- 归档回归覆盖身份一致性、活动/未知状态拒绝、确认要求、节点能力发现、跨重连去重和单会话授权撤销。真实 Desktop 临时会话验证归档，再通过原生恢复及持久化状态核对可恢复性；测试记录不触碰业务会话。
- 检查类型、主测试、编译后的扩展测试、生产构建与中英文文档链接、标题及版本。依赖审计使用 npm 官方 registry：两项低风险，无中、高、严重级别条目；KaTeX/Mermaid 主版本迁移继续单独处理。
- 归档入口只对支持此能力的 PC Connector 显示；Web 不提供恢复列表，需在 Codex 客户端恢复。外部客户端可能在状态检查后启动任务，原生调用冲突会失败，不自动改用删除或强制抢占。
- 保留既有约束：历史/图片源文件需存在；上传临时文件有期限；下载在浏览器组装 Blob；重放保护不是跨进程持久化的“恰好一次”；自动化浏览器检查不能替代手机真机体验验收。
