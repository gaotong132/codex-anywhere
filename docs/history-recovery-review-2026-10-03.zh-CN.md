# 手机后台恢复与图片历史检查（2026-10-03）

本次检查覆盖同一页面在锁屏、后台暂停、断网、重连之后继续阅读历史的流程。

## 已确认的逻辑问题与修复

| 问题 | 触发条件 | 修复 |
| --- | --- | --- |
| 实时片段替换整轮历史 | 一个长任务的输入、图片或早期回复已离开有限尾部窗口 | 实时合并按部分历史处理，保留未返回的记录；完整快照的原有行为不变 |
| 消息标识复用或变化 | 尾部窗口移动，消息索引重新从零开始 | 为同一已知消息保留 DOM 标识；新消息与旧标识冲突时分配独立标识 |
| 进度段落重复 | 尾部窗口从连续进度段落中间开始 | 合并重叠段落并保留原有内容与标识 |
| 进度中的图片丢失 | 带图片的 commentary 被合并到相邻文字，或进入只渲染文字的进度卡片 | 带资源的进度单独保留并展示图片 |
| 图片请求失败后永久空白 | 断网、后台超时或暂时不可读被缓存为空字符串 | 重连、回到页面与手动操作可以重试；已经加载成功的图片继续复用 |
| 图片读取堆积或过期结果回写 | 多图分页或切换会话、连接时请求仍在执行 | 最多三个并发读取，支持取消，已取消的结果不能覆盖当前状态 |
| 旧连接短暂被视为在线 | 主动替换 WebSocket，旧 close 事件被身份保护忽略 | 替换时先清理通道并暂停读取，安全通道就绪后发布新连接代次 |
| 旧历史或会话列表迟到 | 唤醒、连接切换或执行环境切换后旧请求完成 | 取消过期实时轮询，对会话列表验证环境与通道身份；唤醒立即重新同步 |
| 阅读位置被隐藏布局覆盖 | 页面隐藏或视口高度为零时仍发生渲染/滚动事件 | 暂停锚点更新，恢复显示后再定位；支持 pageshow/pagehide |
| 长回复内部文字被图片挤动 | 图片在同一消息中、当前阅读段落上方加载完成 | 增加段落锚点，手机向上阅读时停止自动跟随底部 |

## 验证

- 单元测试覆盖部分历史合并、移动窗口重复标识、重复文字、进度段落重叠、进度图片渲染。
- 图片加载测试覆盖并发上限、取消后迟到响应、失败重试；React hook 测试覆盖重连、唤醒、成功缓存保留和会话隔离。
- 滚动测试覆盖隐藏期间布局变化、同一长消息内部图片增高、分页及手动阅读。
- 使用真实会话与公开 Relay，在 390 × 844 的移动浏览器环境中分页加载 46 条记录、7 张图片；断网并冻结页面 65 秒后恢复，已有记录与图片未减少，锚点偏移为 0，无重复标识或页面异常。

## 边界

- 上述浏览器自动化模拟了冻结与断网，不等于华为手机实际锁屏验收。
- 浏览器彻底回收页面并重新加载时，会重新读取所选会话；本次不增加跨页面重建的完整历史与滚动位置持久化。
- 已从磁盘删除的资源无法通过重试恢复；如果外部应用反复覆盖同一个图片路径，也不能凭当前文件重建过去的图片字节。
