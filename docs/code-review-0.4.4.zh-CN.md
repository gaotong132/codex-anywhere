# v0.4.4 代码审视 — 2026-10-18

[English](code-review-0.4.4.md) | 简体中文

## 范围与取舍

检查环境/会话切换、附件准备与传输、请求重放、加密通道生命周期、历史合并、下载续传、审批/浏览器状态轮询、HTTP 边界和发布检查。现有测试覆盖协议、认证、文件访问及扩展授权。这是基于风险的审查，不代表逐行无缺陷或所有设备均已验证。

保留 Relay/Connector/Web 分层及协议 4。提取两个职责明确的单元：侧栏与文档预览共用的环境切换组件，以及统一负责准备失效和预览释放的附件草稿 hook。没有证据表明全面重写 App 或 Codex 适配器能带来相称收益。

## 发现与修复

| 问题 | 改动与证据 |
| --- | --- |
| 选环境后侧栏自动关闭，随后恢复最近会话也会再次触发关闭。 | 两个以内环境使用直接按钮，固定电脑优先顺序，区分选中与在线状态，并显式控制侧栏关闭。真实认证的 PC/ECS 历史读取在 320/390 px 下检查最近会话恢复和侧栏保留；点击会话后才收起。更多环境保留选择器。 |
| 图片准备乱序完成时覆盖后选文件，移除附件也无法使未完成的处理失效。 | 使用代次校验，仅接受最新结果/错误。替换、移除使旧处理失效，释放未使用的预览 URL；回归测试主动反转完成顺序。 |
| 新建会话弹窗关闭或切换环境后，图片处理仍可能回填。 | 所有关闭入口使准备失效并清空附件；切换环境清空两个附件草稿，切换会话使未完成的聊天附件准备失效；上下文校验丢弃过期结果和错误。 |

## 验证与边界

- 发布门禁包含四组 TypeScript 检查、477 项主测试、100 项扩展构建后测试、生产构建和双语文档检查。
- 手机尺寸浏览器模拟连接真实认证路由，检查直接切换、最近会话、侧栏行为、横向溢出及触摸目标；不据此宣称真机性能或体验通过。
- npm 官方审计仍有 KaTeX/Mermaid 链路的两条低危记录，没有中危、高危或严重记录。Mermaid 12 的浏览器要求和渲染变化需要独立验证，本轮不变更依赖。
- 预览资源会释放，但已经开始的浏览器图片解码不会被强制中止。文件仍为临时存储，浏览器下载仍组装 Blob；重放及文件快照的既有边界见[上一轮审视](code-review-0.4.3.zh-CN.md)。
- 部署须备份并保留 ECS 私有代码改动、身份和注册表，检查活动任务，验证公网 HTTPS、认证 WSS，并保留上一版镜像。私有并发/删除功能不属于公共 tag。
