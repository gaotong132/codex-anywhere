# v0.3.0 — 2026-09-12

[English](release-0.3.0.md) | 简体中文

本版本承接 v0.2.1，核心仍是单用户、自托管的 Codex Web 桥接。Browser Agent 仍属于**实验性附加特性**，默认关闭、单独安装。

## 主要变化

- 浏览器侧栏聊天沿用当前选中的任务。聊天配对一次，自动关联插件的独立身份；页面控制仍需明确授权。
- 八个浏览器工具覆盖页面列表、文字快照、视口截图、独立页签缩放、点击、输入、滚动和打开链接。横向裁剪时优先缩到 80%、67%，每次重新读取快照。
- AI 打开的页签在原窗口跟随，复用符合条件的子页，普通子页保留最近使用的 5 个。同源导航保留授权，跨源目标需要授权；受保护和手动打开的页签不会被自动清理。
- 截图后可 Ctrl/⌘+V 粘贴、预览并发送，上传显示准备、按字节计算的进度和接收确认。每条消息支持一张 PNG/JPEG/WebP 图片。
- Web 可通过选项或自由文本回答 `request_user_input_async`，回复留在原任务、保留输入框草稿，并与 Desktop 同步；已回答卡片和重复问题引用保持精简。
- 兼容旧版和新版 Codex 生成图片事件，补齐历史摘要及大图片记录中的图片；原图仍在时无需重新生成。文本、SVG、代码预览支持可读的受支持绝对路径，位图根目录和确认下载仍分别管理。
- 所选 Codex 运行时提供时可选择 GPT-6 Astra，并保留全部声明的思考档位，包括 Max、Ultra。
- 上下文压缩在同一个时间线标记内原位更新，终止错误保留原因。浏览器状态提示缩为 91 字符，仅首次或状态变化时发送。
- 设备管理支持连接活动和 JSON 输出；历史、文件传输、浏览器驱动补齐隔离和超时处理。Docker 显式设置包元数据读取权限，避免严格目录权限导致非 root 运行账号启动失败。

## 升级

1. 检查所有节点的本地修改和活动任务，保存当前提交、Relay 镜像，以及受保护的私有配置、设备注册表和连接器身份备份。等待连接器持有的任务空闲后再重启，保留业务会话和工作区。
2. 在各节点的干净仓库中获取 tag 并选择已验证版本：

   ```sh
   git fetch origin --tags
   git checkout --detach v0.3.0
   npm ci
   npm run build
   ```

3. Relay 主机执行 `docker compose build bridge` 与 `docker compose up -d --no-build bridge`；同机 Connector 安装且空闲后再重启。验证容器健康、公网 HTTPS 和全部 Connector。参考健康探测间隔为 30 秒，启动宽限期为 10 秒；检查失败原因，不能把构建成功当作服务正常。
4. Windows 完成构建后，通过现有启动器或安装器重启 Connector，保留配置与 DPAPI 身份文件，不停止 Codex Desktop 或其他任务。Linux 在同版构建完成后重启 `codex-anywhere-connector.service`。
5. 完整刷新 Web，或在侧栏选择“重新加载聊天”。检查一张已有生成图片、一个受支持的文件预览，以及目标节点上的无害测试任务。现有设备配对继续有效。
6. 使用 Browser Agent 时，执行 `npm run build:extension`，保留 `extension/dist` 的原安装路径并重新加载插件，核对版本和构建指纹。宿主空闲时重载 MCP 工具列表并确认八个工具。较旧插件升级可能提示 `debugger` 或 `webNavigation` 权限，本 tag 相比此前 main 构建没有新增权限。

`relay.sh update` 跟随 `main`，固定使用此 tag 时请按上述步骤操作。后续升级仍需协调 Relay、Web 和全部 Connector。验证失败时恢复保存的匹配代码、镜像与配置，不要通过重建设备注册表或配对身份恢复服务。

## 在其他电脑安装插件

从此 tag 构建，把 **`extension/dist` 整个目录**复制到另一台电脑的固定位置。该目录是构建产物，不提交 Git；源码和构建配置已提交。在 Chrome/Edge 扩展管理页加载该目录，把该安装实例的精确扩展 Origin 加入 Relay 白名单，在新浏览器配置中配对聊天一次，再明确授权目标页面。不要复制其他安装实例的浏览器配置、私钥或单次凭据。详见[插件指南](../extension/README.zh-CN.md)。

## 验证与限制

2026-09-12 发布验证：全部类型检查与 389 项主测试通过，Web/Node 构建及 100 项扩展测试通过；24 份 Markdown 文档的本地链接和标题锚点检查通过。插件构建指纹为 `0ad9ef11`。package、lockfile、扩展源清单和 MCP 服务端统一为 0.3.0。插件仍显示 `dev (build …)`，表示未打包商店发布的实验构建；Git tag 标识发布版本，指纹标识具体产物。

带日期的浏览器验收和重构报告保留当时的测试结果，不代表此次重新验收全部网站。任意脚本、Cookie/密码导出、iframe/shadow DOM 内控件、原生对话框和浏览器文件上传仍不支持。截图遮挡不保证识别所有秘密，缩放不能替代分页、懒加载或突破快照限制。实际登录、验证码、新站点权限和任务范围外的操作仍需要用户参与。
